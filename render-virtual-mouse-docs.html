Render Virtual Mouse

Control your cursor with hand gestures using Computer Vision.

info Overview

An experimental Human-Computer Interaction (HCI) application built with Python, OpenCV, and MediaPipe. Unlike standard gesture controllers, this app features a dual-display interface: a live webcam diagnostic feed and a dedicated, high-performance "Virtual Mouse" window that renders an animated multi-cursor visual.

checklist Key Features

  • Dual-Window Architecture — A webcam monitor showing real-time hand landmark detection alongside a stylized virtual workspace with animated multi-cursor visuals
  • Pinch-to-Action Gestures — Navigation controlled via the tip of the Index Finger (Landmark 8); performs a "Left Click" when Thumb and Index Finger distance falls below a dynamic threshold
  • Animated Visual Feedback — The cursor isn't just a dot; it uses velocity-aware animation that grows, shrinks, and leaves trails based on hand speed and gesture state
  • Precision Smoothing — Moving Average Filter eliminates jitter, ensuring fluid and intentional cursor movement

settings How It Works

The application captures live video from your webcam and processes each frame through the MediaPipe Hands pipeline to extract 21 landmark points per hand. The index finger tip controls cursor position, while the distance between thumb and index finger determines click actions. A separate window renders the virtual mouse interface with animated visual effects synchronized to your hand movements.

code Tech Stack

Python 3 MediaPipe OpenCV PyAutoGUI

Built with Python 3.x as the core language. MediaPipe Hands provides high-fidelity 21-point 3D hand tracking, OpenCV handles video capture and rendering for both the diagnostic feed and the virtual mouse window, and PyAutoGUI bridges gestures to OS-level mouse events.

terminal Setup

Clone the repository and install the required dependencies:

git clone https://github.com/RishabhKothiyal1/Virtual-Mouse-Control.git
cd Virtual-Mouse-Control
pip install opencv-python mediapipe pyautogui numpy

Run the application:

python main.py

hand_gesture Gesture Reference

  • Move Cursor — Point your index finger; the cursor follows the fingertip position
  • Left Click — Bring your thumb and index finger close together (pinch)
  • Drag — Pinch and hold while moving your hand
  • Right Click — Pinch with middle finger and thumb (extended gesture)
