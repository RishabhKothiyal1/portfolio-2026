Streamie

A seamless web-based streaming platform for movies and series.

info Overview

Streamie is a web-based streaming platform that lets users browse and watch movies and series seamlessly. It integrates multiple external APIs to dynamically fetch content metadata, trailers, and streaming links — all within a clean, responsive interface.

checklist Features

  • Browse movies and series with dynamic content discovery
  • Search functionality to find titles instantly
  • Detailed content pages with synopsis, trailers, and ratings
  • Multiple external API integrations for rich metadata
  • Responsive design — works on desktop, tablet, and mobile
  • Clean, modern UI with smooth navigation

code Tech Stack

JavaScript REST API HTML/CSS

Built with vanilla JavaScript for the frontend logic. REST APIs are consumed to fetch real-time content data, trailers, and streaming information. The UI is styled with clean HTML and CSS.

play_arrow How to Use

  1. Open Streamie in your browser.
  2. Browse the featured movies and series on the home page.
  3. Use the search bar to find specific titles.
  4. Click on a title to view details, trailers, and streaming options.
