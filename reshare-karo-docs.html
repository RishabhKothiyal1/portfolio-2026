Reshare Karo

A secure and seamless file sharing platform built with React, Node.js, MongoDB, and Express.

info Overview

Reshare Karo is a file sharing platform that lets users upload files and share them instantly with a generated link. Built with a focus on security, speed, and simplicity — no accounts required.

Upload any file, get a shareable link, and send it to anyone. The recipient can download the file directly from the link without any registration.

checklist Features

  • Drag-and-drop file upload interface
  • Instant shareable link generation
  • No user accounts or authentication required
  • Secure file storage with MongoDB
  • Responsive design for all devices
  • File expiration and auto-cleanup

code Tech Stack

React Node.js MongoDB Express

The application uses a MERN stack architecture with React on the frontend and Node.js/Express on the backend, with MongoDB for file metadata storage.

play_arrow How to Use

  1. Open Reshare Karo in your browser.
  2. Drag your file into the upload area or click to browse.
  3. Wait for the upload to complete.
  4. Copy the generated share link and send it to anyone.
  5. The recipient opens the link and downloads the file instantly.

api API Reference

POST /api/upload — Upload a file

FormData: { file: File }

Response:

{
  "success": true,
  "fileId": "abc123",
  "shareUrl": "https://resharekaro.qzz.io/share/abc123"
}

GET /api/download/:fileId — Download a file

Returns the file binary with the correct content-type header.
